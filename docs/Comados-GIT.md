## Iniciamos con GIT
```
git init
git add .
git commit -m "Proyecto base Vue"
git remote add origin <direccion_remota_github>
git push origin master
```
## Crear una rama develop
```
git checkout -b develop
git push -u origin develop
```
# Iniciando con GIT FLOW
```
git flow init
```
## Trabajar con features usando pull request
```
git flow feature start habilitando-servicios
```
